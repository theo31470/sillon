# Charte Tracteurs & Co

- **Nom** : Tracteurs & Co — signature « Machinisme agricole ».
- **Couleurs du logo** : blanc `#FFFFFF`, terre cuite `#E0875A`, beige `#C9C1B5` (signature).
- **Polices** : Barlow (titres, logo), Inter (textes).
- `logo/` : déclinaisons d'origine (fond sombre) — D1 intégral blanc, D2 blanc + terre cuite (logo principal),
  D3 sans signature, D4 italique, D5 verticale, D6 emblème, D7/D8 icône « CO ».
- `public/brand/` : versions compressées utilisées par le site, en `-sombre` (texte blanc) et `-clair`
  (texte #1B1916, signature #6B6358) pour le mode clair.
